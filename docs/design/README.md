# Design direction

## North star reactions

1. That looks beautiful.
2. I immediately understand this.
3. I want to touch that.
4. This feels like a real game.
5. Send me another one.

## Principle

**Quiet shell. Loud game.** (Same intent as product “quiet platform, loud game.”)

The platform chrome stays minimal; each game owns its visual energy during play.

## Qualities

- Mobile-first
- Clean, premium, playful, social, modern, approachable, fast
- Minimal chrome during gameplay
- Game-specific visual identity inside the play surface
- Accessible interaction targets and readable type

## Avoid

Generic SaaS dashboards, heavy glassmorphism/gradients/shadows, casino/crypto aesthetics, childish or esports-dashboard clones, Discord/WhatsApp cloning, excessive pills and motion, UI clutter.

## Phase 0

No final visual system. `packages/ui` holds minimal primitives only; `apps/web` shows a temporary landing shell.
